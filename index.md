# RHEL Enterprise Lab

## From installation to professional operation

This site documents a real RHEL laboratory built around enterprise practices.

The objective is to demonstrate not only that RHEL can be installed, but that a system can be:

**designed → secured → operated → automated → broken safely → recovered → evidenced → documented**

## Why this laboratory exists

RHEL was selected deliberately because enterprise Linux administration is a real professional capability. The laboratory is therefore designed to reproduce the disciplines used in production environments while remaining safe and small enough for a laptop.

## Current phase

**USB preparation / installation pending.**

The first RHEL boot will create Baseline 0. No final system-state claims are published until that baseline exists.

## Architecture

The laboratory is organized around:

- base administration;
- security;
- system services;
- storage;
- networking;
- development;
- containers;
- automation;
- monitoring;
- incident response;
- AI-assisted operations;
- evidence and portfolio.

## Professional standard

Every major capability follows:

**SPECIFIED → IMPLEMENTED → VERIFIED → EVIDENCED → DOCUMENTED**

## Portfolio value

The final Pages site will present:

- architecture decisions;
- security posture;
- reproducible procedures;
- controlled incident exercises;
- automation;
- evidence;
- lessons learned;
- AI governance.

This makes the project useful both as a learning environment and as a demonstrable professional systems-engineering portfolio.

# Skill: RHEL Administrator

Execute controlled administration tasks while preserving reversibility and evidence.

Rules:

- Read AI contracts first.
- Prefer non-privileged discovery.
- Use least privilege.
- Never modify storage or boot without explicit authorization.
- Validate configuration before restarting services.
- Verify after every change.
- Record rollback.

Lifecycle:

DISCOVER → PLAN → AUTHORIZE → CHANGE → VERIFY → EVIDENCE → DOCUMENT

Never report done without successful verification.

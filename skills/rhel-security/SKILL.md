# Skill: RHEL Security Engineer

Assess and improve host security using native RHEL controls.

Focus:

- SELinux
- firewalld
- SSH
- sudo
- permissions
- audit
- package integrity
- service exposure

Method:

BASELINE → THREAT MODEL → CONTROL → CHANGE → VERIFY → EVIDENCE

Do not disable security controls merely to make a service work. Diagnose the conflict and document the least-privilege solution.

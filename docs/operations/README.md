# Operations

## Reference: command language

The [RHEL/Linux Command Reference](../learning/rhel-linux-command-reference.md) is the canonical learning reference for basic and important commands, shell syntax, administration, diagnostics and high-risk operations.

Required runbooks:

- installation and recovery;
- package lifecycle;
- users and sudo;
- SSH;
- firewalld;
- SELinux;
- systemd;
- journald;
- storage;
- network;
- Podman;
- backups;
- incident response.

Every runbook states purpose, preconditions, commands, expected result, verification, rollback, failure modes and evidence.

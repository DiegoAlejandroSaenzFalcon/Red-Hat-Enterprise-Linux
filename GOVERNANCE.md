## Definition of done

A task is complete only when:

1. Requirement exists.
2. Design/decision exists where necessary.
3. Implementation exists.
4. Verification exists.
5. Evidence is captured.
6. Documentation is updated.
7. Git commit exists.
8. GitHub reflects the completed state.

## Status vocabulary

- PLANNED
- SPECIFIED
- IMPLEMENTED
- VERIFIED
- EVIDENCED
- DOCUMENTED
- BLOCKED
- DEPRECATED

## Change control

Security, network exposure, storage, authentication, privileged services and boot changes require rationale, rollback plan, verification command and evidence.

## Evidence rule

Documentation is not evidence. A command that claims success is not evidence. Evidence is an observable result produced by the target system.

## AI governance

AI is an assistant and controlled operator, never the final authority. Every AI-assisted operation identifies actor, task, scope, permissions, change, verification, result, evidence and rollback when relevant.

## Public portfolio rule

Pages must not expose credentials, private infrastructure addresses, sensitive logs, unpublished incident details or exploitable weaknesses.

Public documentation demonstrates competence through architecture, methodology, evidence and reproducibility.
